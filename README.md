# Карти для Kurs

Повні офлайн-пакети для застосунку Kurs: дороги для маршрутів, вулиці,
будівлі та підписи. Для завантаження обліковий запис GitHub не потрібен.

## Завантажити

- **[Вся Україна](https://github.com/jarakys/kurs-maps/releases/download/maps-2026-10-09/Ukraine.kursmap)** — один пакет для маршрутів між областями; дані від 27 вересня 2026.

- [Дніпро та область](https://github.com/jarakys/kurs-maps/releases/download/maps-2026-10-09/Dnipro-Region.kursmap)
- [Харків та область](https://github.com/jarakys/kurs-maps/releases/download/maps-2026-10-09/Kharkiv-Region.kursmap)
- [Київ та область](https://github.com/jarakys/kurs-maps/releases/download/maps-2026-10-09/Kyiv-Region.kursmap)
- [Київ — місто](https://github.com/jarakys/kurs-maps/releases/download/maps-2026-10-09/Kyiv-City.kursmap)

Завантажуйте саме файл `.kursmap`. Архіви GitHub «Source code (zip)» / «Source
code (tar.gz)» не є картами для застосунку.

## Установити на iPhone

1. Відкрийте посилання в Safari та завантажте файл у «Файли» → «Завантаження».
2. Не розпаковуйте його. Якщо браузер додав розширення `.zip`, імпорт ZIP також
   підтримується актуальною версією Kurs.
3. У Kurs відкрийте **Налаштування → Офлайн-карти → Імпортувати з «Файлів»**.
4. Оберіть завантажений пакет та дочекайтеся встановлення.
5. Перевірте, що потрібний регіон активний; за потреби натисніть **Показати на карті**.

Карту встановлюйте до початку ведення. Сам імпорт потребує вільного місця для
архіву й розпакованої карти. Після встановлення карта та локальний розрахунок
маршруту працюють без інтернету.

## Каталог для вбудованого завантаження

У Kurs 0.9.18 каталог підключений за замовчуванням: відкрийте «Офлайн-карти» з інтернетом. Для попередніх версій у полі **Каталог карт** на цьому ж екрані вкажіть:

```text
https://github.com/jarakys/kurs-maps/releases/latest/download/catalog.json
```

Натисніть **Перевірити оновлення**. Після успішного завантаження каталогу доступні
регіони можна завантажувати кнопкою в застосунку. Якщо завантаження обірветься,
його можна повторити; ця версія завантажувача не гарантує фонове продовження.

## Покриття та дані

Пакет «Україна» містить єдиний граф усього українського витягу Geofabrik, включно з Кримом. Маршрути між областями не потребують перемикання карт. Межі в manifest задають прямокутник охоплення, а не обіцянку доріг у кожній точці. Менші пакети — прямокутні регіональні витяги, не точні адміністративні межі. Обидві точки
маршруту мають поміщатися в одному активному пакеті; встановлення двох областей
не зшиває їхні дорожні графи. Дата публікації пакета не є датою актуалізації OSM.

- Україна: граф і тайли з одного знімка OSM від 27 вересня 2026.
- Київ/Київська область/Дніпро: дорожні дані OSM від 27 вересня 2026.
- Харків: дорожній граф від 23 вересня 2026, тайли від 27 вересня 2026.
- Для Київської та Дніпропетровської областей тайли повторно зібрані з того ж
  вересневого витягу 9 жовтня; дорожні графи збережено без змін.

доступні за [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
Розповсюджувані похідні дорожні бази та OSM-дані тайлів також доступні за ODbL 1.0.
Їх повний машинозчитуваний вміст надається в кожному `.kursmap`: це ZIP з
`graph.navpack`, `map.pmtiles` та `manifest.json` з контрольними сумами.
Контрольні суми повних архівів містяться у `SHA256SUMS.txt` релізу.

Джерело витягів — [Geofabrik Ukraine](https://download.geofabrik.de/europe/ukraine.html).
Схема та картографічні матеріали — © [OpenMapTiles](https://openmaptiles.org/),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Тайли створено [Planetiler](https://github.com/onthegomap/planetiler), формат
[PMTiles](https://github.com/protomaps/PMTiles). Допоміжні географічні дані:
[Natural Earth](https://www.naturalearthdata.com/) і
[OSM water polygons](https://osmdata.openstreetmap.de/data/water-polygons.html).

Цей репозиторій поширює карти. Наявність пакета не є підтвердженням проходження
польових випробувань навігації на всіх дорогах регіону.

## Межі бета-версії

У новому пакеті України виправлено перенесення заборон розвороту та збереження вузлів і доріг, на які посилаються обмеження. Попередні регіональні архіви не змінені. Обмеження через кілька проміжних доріг (via-way) та умовні обмеження за часом ще не підтримуються повністю; нерозв’язані відношення не вгадуються. Дані не містять оперативної інформації про перекриття, небезпечні ділянки чи фактичну доступність доріг. Наявність дороги в пакеті не підтверджує можливість проїзду сьогодні.
